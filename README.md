以後要改資料，只修改 config.js：
- announcement：本週活動
- booking：六日表單
- links：社群網址
- business：營業時間與地址

上傳方式：
1. 保留 GitHub 內的 CNAME。
2. 解壓縮 ZIP。
3. GitHub → Add file → Upload files。
4. 上傳全部檔案並 Commit changes。
5. 等待 1～2 分鐘，開啟 https://victorcard.tw 後按 Ctrl + F5。
