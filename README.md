# Victor Card Website Professional Edition 2026 — Release 1

## Upload to GitHub
1. Keep the existing `CNAME` file in GitHub.
2. Extract this ZIP.
3. In GitHub, choose **Add file → Upload files**.
4. Upload all extracted files.
5. Select **Commit changes**.
6. Wait about 1–2 minutes.
7. Open `https://victorcard.tw/?release=1`.
8. Press `Ctrl + F5`.

## Common updates
Edit `config.js` to change:
- Saturday booking form
- Sunday booking form
- LINE
- Instagram
- Facebook
- Threads
- Google Maps
- Google review
- Business hours
- Address
